# 手動驗證清單

## 啟動

1. 在專案根目錄執行 `go run ./cmd/tetris`。
2. 確認程式會開啟一個桌面視窗，而不是輸出在 terminal 內。
3. 確認視窗內成功顯示棋盤、分數、等級、消行數與下一個方塊預覽。

## 基本操作

1. 按 `←` 或 `A`，確認作用中方塊會向左移動，且不會穿過左邊界。
2. 按 `→` 或 `D`，確認作用中方塊會向右移動，且不會穿過右邊界。
3. 按 `↑` 或 `W`，確認作用中方塊會旋轉；在靠牆位置時，確認非法旋轉不會讓方塊穿牆或重疊。
4. 按 `↓` 或 `S`，確認作用中方塊會比自然下落更快往下。

## 遊戲流程

1. 讓方塊自然落下到底部，確認方塊會鎖定到棋盤上。
2. 堆出一整行後，確認該行會被清除，並且上方方塊會下移。
3. 消除至少一行，確認分數會增加。
4. 持續消行到等級提升，確認等級數字會更新，且下落速度變快。
5. 讓出生區被堆滿，確認遊戲會顯示遊戲結束提示。

## 狀態切換

1. 遊戲進行中按 `P`，確認畫面顯示暫停提示。
2. 暫停時按方向鍵或旋轉鍵，確認棋盤狀態不會變動。
3. 再按一次 `P`，確認遊戲恢復進行。
4. 在遊戲進行中或遊戲結束後按 `R`，確認棋盤、分數、等級與消行數會重設。

## 離開

1. 按 `Q` 或 `Esc`，確認程式能正常結束。
